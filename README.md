# 🚀 DSA Practice in C++

Welcome to my **DSA Practice Repository**! 👋

This repository contains my daily solutions to **Data Structures and Algorithms (DSA)** problems solved in **C++**. The problems are organized topic-wise to improve problem-solving skills and prepare for coding interviews and placement exams.

---

## 📌 About

- 💻 Language: **C++**
- 📚 Platform: LeetCode, GeeksforGeeks & other coding platforms
- 🎯 Goal: Strengthen DSA concepts and improve coding interview skills
- 🔥 Daily practice with well-structured solutions

---

## 📂 Topics Covered

| Topic | Description |
|--------|-------------|
| 📌 Prefix Sum | Prefix Sum techniques and range queries |
| 🔁 Sliding Window | Fixed & Variable Window problems |
| 📚 Stack | Monotonic Stack, Next Greater Element, Valid Parentheses, etc. |
| 🔗 Linked List | Reversal, Sorting, Cycle Detection, Merge Lists |
| ➡️ Two Pointer | Pair problems, Array manipulation, String problems |
| 📈 Kadane Algorithm | Maximum Subarray variations |
| 🔀 Merge Intervals | Interval scheduling and merging |

More topics will be added regularly.
